# Installing the SCM Service

The **SCM** (Supply Chain Management) service manages vendors, purchase orders, goods receipts, shipments, and inventory.

- **Port:** 8081
- **Database:** SQLite (file-based, no external DB server needed)
- **Image:** `ghcr.io/se359-zeus/zeus-be/scm:latest`

---

## Prerequisites

### Bare Metal
- **Go 1.25+**
- **GCC / build-base** (CGO is required for the `mattn/go-sqlite3` driver)
- **SQLite3 dev headers** -- `apk add sqlite-dev` (Alpine), `apt install libsqlite3-dev` (Debian/Ubuntu)
- **Valkey** or **Redis** (optional, for caching)
- **RabbitMQ** (optional, for inter-service messaging)

### Docker
- **Docker 24+** with Compose V2

---

## Configuration

SCM reads a `.env` file in its working directory or environment variables directly.

```env
# ── Required ────────────────────────────────────────────────────────────────
SERVER_PORT=8081
DB_PATH=scm.db
JWT_PUBLIC_KEY_PATH=jwt_public.pem

# ── Optional: cache ─────────────────────────────────────────────────────────
VALKEY_ADDR=redis://localhost:6379

# ── Optional: message broker ────────────────────────────────────────────────
RABBITMQ_URL=

# ── Optional: public URL for Swagger UI ─────────────────────────────────────
PUBLIC_BASE_URL=http://localhost:8081

# ── Optional: observability ─────────────────────────────────────────────────
APP_ENV=development
ALLOY_URL=
ALLOY_USERNAME=
ALLOY_PASSWORD=
```

### Environment Variable Reference

| Variable              | Code Default                       | Description                              |
|-----------------------|------------------------------------|------------------------------------------|
| `SERVER_PORT`         | `8080` (`.env` overrides to `8081`) | HTTP listen port                        |
| `DB_PATH`             | `scm.db`                           | SQLite database file path                |
| `RABBITMQ_URL`        | (empty)                            | RabbitMQ connection URL                  |
| `VALKEY_ADDR`         | `redis://localhost:6379`           | Valkey/Redis address                     |
| `JWT_PUBLIC_KEY_PATH` | (empty)                            | Path to RSA public key PEM               |
| `PUBLIC_BASE_URL`     | `http://localhost:8081`            | Base URL for OpenAPI spec server field   |
| `AGING_THRESHOLD_YEARS` | `5`                              | Threshold for aging inventory reports    |
| `APP_ENV`             | `production`                       | `development` / `staging` / `production` |
| `ALLOY_URL`           | (empty)                            | Alloy Loki-receiver for log push         |
| `ALLOY_USERNAME`      | (empty)                            | Grafana Cloud user ID                    |
| `ALLOY_PASSWORD`      | (empty)                            | Grafana Cloud API token                  |

### JWT

SCM verifies incoming JWTs with an RSA public key. The key pair is generated by the **System** service (see [INSTALL_SYSTEM.md](INSTALL_SYSTEM.md)). Copy the public key to `scm/jwt_public.pem` and set `JWT_PUBLIC_KEY_PATH` accordingly.

## Option 1: Bare Metal

```bash
cd scm/

# 1. Install Go dependencies
go mod download

# 2. Run migrations (currently a no-op -- GORM auto-creates the schema)
make migrate

# 3. Start the server
make run
#    Listening on http://localhost:8081
#    Swagger UI: http://localhost:8081/docs/
```

### Available Make Targets

| Command         | Description                                    |
|-----------------|------------------------------------------------|
| `make run`      | Start the SCM server                           |
| `make build`    | Compile binary to `build/zeus-scm`             |
| `make seed`     | Seed the database (deletes existing DB first!) |
| `make backfill` | Backfill parts for products with no parts      |
| `make migrate`  | Run SQL migrations (currently a no-op)         |
| `make test`     | Run all tests                                  |
| `make dev`      | Run with live reload via [air](https://github.com/air-verse/air) |

> **Note:** The `make seed` CLI binary only supports `--backfill` mode. Full seeding
> (catalogs, suppliers, inventory) is done via the API endpoints under
> `POST /api/v1/scm/seeding/`. The server also auto-backfills parts on startup.

## Option 2: Docker

### Build

Build from the **repo root** (the Dockerfile expects a monorepo context):

```bash
docker build -f scm/Dockerfile -t zeus-scm:latest .
```

### Run

```bash
# 1. Start Valkey (optional)
docker run -d --name zeus-scm-valkey \
  -p 6380:6379 \
  valkey/valkey:8-alpine

# 2. Run migrations (no-op, but safe)
docker run --rm \
  -v zeus-scm-data:/app/data \
  zeus-scm:latest \
  ./migrate -db /app/data/scm.db

# 3. Seed (optional -- server auto-backfills on startup)
docker run --rm \
  -v zeus-scm-data:/app/data \
  zeus-scm:latest \
  ./seeder -db /app/data/scm.db -backfill

# 4. Start the server
docker run -d --name zeus-scm \
  -p 8081:8081 \
  -v zeus-scm-data:/app/data \
  -e SERVER_PORT=8081 \
  -e DB_PATH=/app/data/scm.db \
  -e JWT_PUBLIC_KEY_PATH=jwt_public.pem \
  -e VALKEY_ADDR=redis://zeus-scm-valkey:6379 \
  -e APP_ENV=development \
  --link zeus-scm-valkey \
  zeus-scm:latest
```

### Docker Compose (Valkey only)

The included `scm/docker-compose.yml` starts just Valkey:

```bash
cd scm/
docker compose up -d   # Valkey on port 6380
```

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| `failed to open sqlite db` | Missing write permission or directory | Ensure the DB directory exists and is writable |
| `valkey unavailable` warning | Valkey not running | Non-fatal; service runs without caching |
| `rabbitmq unavailable` warning | RabbitMQ not running | Non-fatal; service runs without messaging |
| CGO compilation error | Missing C toolchain | Install `build-base` + `sqlite-dev` |
| JWT verification errors | Wrong or missing public key | Ensure `JWT_PUBLIC_KEY_PATH` points to a valid RSA PEM |
