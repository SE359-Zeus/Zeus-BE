# Installing the MRP Service

The **MRP** (Material Requirements Planning) service handles production planning, BOM explosion, and Clear-to-Build checks.

- **Port:** 8083
- **Database:** SQLite
- **Image:** `ghcr.io/se359-zeus/zeus-be/mrp:latest`
- **Depends on:** SCM (pings `/health` at startup), System (JWT auth)

---

## Prerequisites

### Bare Metal
- **Go 1.26+**
- **GCC / build-base** (CGO required for SQLite)
- **SQLite3 dev headers**
- **Valkey** or **Redis** (optional)
- **RabbitMQ** (optional)

### Docker
- **Docker 24+** with Compose V2

---

## Configuration

MRP reads a `.env` file in its working directory or environment variables directly. All config keys are prefixed with `MRP_`.

```env
# ── Required ────────────────────────────────────────────────────────────────
MRP_PORT=8083
MRP_DB_PATH=./mrp.db
JWT_PUBLIC_KEY_PATH=jwt_public.pem

# ── Required: cross-service URLs ────────────────────────────────────────────
SCM_BASE_URL=http://localhost:8081
SALES_BASE_URL=http://localhost:8082
SYSTEM_BASE_URL=http://localhost:8085

# ── Optional: cache ─────────────────────────────────────────────────────────
MRP_VALKEY_ADDR=redis://localhost:6379

# ── Optional: message broker ────────────────────────────────────────────────
MRP_RABBITMQ_URL=

# ── Optional: observability ─────────────────────────────────────────────────
MRP_ENV=development
ALLOY_URL=
ALLOY_USERNAME=
ALLOY_PASSWORD=
```

### Environment Variable Reference

| Variable               | Code Default                       | Description                              |
|------------------------|------------------------------------|------------------------------------------|
| `MRP_PORT`             | `8081` (`.env` overrides to `8083`) | HTTP listen port                        |
| `MRP_DB_PATH`          | `mrp.db`                           | SQLite database file path                |
| `MRP_VALKEY_ADDR`      | `redis://localhost:6379`           | Valkey/Redis address                     |
| `MRP_RABBITMQ_URL`     | (empty)                            | RabbitMQ connection URL                  |
| `JWT_PUBLIC_KEY_PATH`  | (empty)                            | Path to RSA public key PEM               |
| `MRP_BASE_URL`         | `http://localhost:<port>`          | Service base URL                         |
| `SCM_BASE_URL`         | `http://localhost:8083`            | SCM service URL (pinged at startup)      |
| `SALES_BASE_URL`       | `http://localhost:8082`            | Sales service URL                        |
| `SYSTEM_BASE_URL`      | `http://localhost:8085`            | System service URL                       |
| `MRP_ENV`              | `development`                      | `development` / `staging` / `production` |
| `ALLOY_URL`            | (empty)                            | Alloy Loki-receiver for log push         |
| `ALLOY_USERNAME`       | (empty)                            | Grafana Cloud user ID                    |
| `ALLOY_PASSWORD`       | (empty)                            | Grafana Cloud API token                  |

### JWT

MRP verifies incoming JWTs with an RSA public key. Copy the public key generated by the **System** service to `mrp/jwt_public.pem`.

## Option 1: Bare Metal

```bash
cd mrp/

# 1. Install Go dependencies
go mod download

# 2. Run database migrations
make migrate

# 3. Seed the database (optional)
#    Requires mrp/contracts/scm-manifest.json -- generated by the SCM seeder.
#    See "Seeding" section below.
make seed

# 4. Start the server
make run
#    Listening on http://localhost:8083
#    Swagger UI: http://localhost:8083/docs/
```

### Available Make Targets

| Command        | Description                             |
|----------------|-----------------------------------------|
| `make run`     | Start the MRP server                    |
| `make build`   | Compile binary to `bin/mrp`             |
| `make migrate` | Run database migrations                 |
| `make seed`    | Seed the database from scm-manifest     |
| `make test`    | Run all tests                           |
| `make fmt`     | Run `go vet` and `go fmt`               |

### Seeding

The MRP seeder reads from `mrp/contracts/scm-manifest.json`, which is generated by the SCM seeder. To seed:

1. Run the SCM seeder first (see [INSTALL_SCM.md](INSTALL_SCM.md))
2. Copy the generated `scm-manifest.json` to `mrp/contracts/scm-manifest.json`
3. Run `make seed` (override path: `make seed MANIFEST=/path/to/manifest.json`)

## Option 2: Docker

### Build

Build from the **repo root**:

```bash
docker build -f mrp/Dockerfile -t zeus-mrp:latest .
```

### Run

```bash
# 1. Start Valkey (optional)
docker run -d --name zeus-mrp-valkey \
  -p 6381:6379 \
  valkey/valkey:latest

# 2. Run migrations
docker run --rm \
  -v zeus-mrp-data:/app/data \
  zeus-mrp:latest \
  ./migrate -db /app/data/mrp.db

# 3. Seed (optional -- requires scm-manifest.json baked into the image)
docker run --rm \
  -v zeus-mrp-data:/app/data \
  zeus-mrp:latest \
  ./seeder -db /app/data/mrp.db

# 4. Start the server
docker run -d --name zeus-mrp \
  -p 8083:8083 \
  -v zeus-mrp-data:/app/data \
  -e MRP_PORT=8083 \
  -e MRP_DB_PATH=/app/data/mrp.db \
  -e JWT_PUBLIC_KEY_PATH=jwt_public.pem \
  -e MRP_VALKEY_ADDR=redis://zeus-mrp-valkey:6379 \
  -e SCM_BASE_URL=http://host.docker.internal:8081 \
  -e SALES_BASE_URL=http://host.docker.internal:8082 \
  -e SYSTEM_BASE_URL=http://host.docker.internal:8085 \
  -e MRP_ENV=development \
  --link zeus-mrp-valkey \
  zeus-mrp:latest
```

### Docker Compose (production-style)

The included `mrp/docker-compose.yml` defines a full production stack with Tailscale networking, Valkey, migration, seeder, and the server. See that file for details.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| `scm connection failed` at startup | SCM not running | Start SCM first; check `SCM_BASE_URL` |
| `failed to open sqlite db` | Missing write permission | Ensure DB directory is writable |
| `valkey unavailable` warning | Valkey not running | Non-fatal; runs without caching |
| `rabbitmq unavailable` warning | RabbitMQ not running | Non-fatal; runs without messaging |
| Seeder fails with manifest error | Missing `scm-manifest.json` | Generate from SCM seeder first |
| CGO compilation error | Missing C toolchain | Install `build-base` + `sqlite-dev` |
